# Ảnh minh hoạ cho bài học

Bỏ ảnh vào đây để **thay tranh SVG mặc định** của từng bài.

## Cách đặt tên
Đặt tên file **trùng mã bài học** (cột mã ở đầu mỗi dòng bài, ví dụ `1.1.1`, `2.3.4`):

```
images/1.1.1.jpg
images/1.1.2.png
images/2.3.4.webp
```

- Định dạng hỗ trợ (tự dò theo thứ tự): `.png` → `.jpg` → `.webp` → `.jpeg`
- Nếu **không có** ảnh cho bài đó, web tự hiện **tranh SVG vẽ theo chủ đề** (không cần làm gì thêm).
- Kích thước gợi ý: ngang, khoảng **800×450** (tỉ lệ 16:9) cho đẹp trên banner.

## Gợi ý tạo ảnh bằng AI
Có thể dùng công cụ tạo ảnh (ví dụ hình do AI vẽ) rồi lưu đúng tên mã bài như trên.
Nội dung ảnh nên liên quan chủ đề bài, phong cách vui tươi, phù hợp trẻ em.
